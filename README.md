# Hospital Pre-Visit Intake LLM Chatbot
An LLM-based chatbot system designed for hospital pre-visit patient intake.

## Tech Stack
- React 18
- TypeScript
- Vite
- Tailwind CSS

## Getting Started
### 1. Install Dependencies
```bash
npm install
```
### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
